# Справка по клавишам и безопасное удаление worktree

## Цель

Сделать все сочетания Vigit доступными из интерфейса и хранить их в одном
источнике, а также разрешить безопасное удаление открытой worktree без риска
потерять изменения или незапушенные commits.

## Справка по клавишам

- `lua/vigit/keymaps.lua` становится единым реестром сочетаний: context, mode,
  key, action и description.
- Все buffer-local mappings Vigit получают `desc`, поэтому установленные
  WhichKey и стандартные средства Neovim видят реальные действия.
- `?` открывает контекстную справку в собственных окнах Vigit: changes, diff,
  worktree picker и comments.
- В обычном editor и terminal `?` не переопределяется. Полная справка там
  доступна через команду `:VigitHelp`.
- Popup сначала показывает текущий context, затем остальные группы. `q` и
  `<Esc>` закрывают справку.
- Короткие hints в winbar содержат только основные действия и `? help`.
- README сохраняет компактную таблицу основных сочетаний.

Vigit не зависит от WhichKey: встроенная справка работает самостоятельно, а
`desc` обеспечивает совместимость при наличии плагина.

## Безопасное удаление worktree

Picker показывает upstream-состояние ветки: `PUSHED`, `↑N`, `↓N` или
`NO UPSTREAM`. Удаление по `d` разрешено только когда:

1. выбранная запись не является `ROOT`;
2. Git status полностью clean;
3. ветка не detached и имеет upstream;
4. локальная ветка не содержит незапушенных commits (`ahead == 0`).

Отставание локальной ветки от upstream (`↓N`) не блокирует удаление: remote уже
содержит все локальные commits. Проверка использует локальный upstream ref и не
выполняет скрытый сетевой `fetch`.

После подтверждения `y` Vigit повторяет проверку, затем закрывает связанную
вкладку, удаляет worktree через Git и сохраняет ветку. Незакрываемый editor с
modified buffers, изменённые файлы, `↑N`, detached HEAD или отсутствие
upstream блокируют операцию с точной причиной.

## Исправление untracked-файлов

При построении diff Vigit переносит status из `git status` в модель diff-файла.
Поэтому `x` и `X` распознают untracked-файл и удаляют его через `git clean`
после подтверждения, вместо ошибочного `git restore`.

## Проверка

- Unit-сценарии для upstream/ahead/behind и условий удаления worktree.
- Regression-сценарий: `X` удаляет untracked-файл из one-file diff.
- UI-сценарии для `?`, `:VigitHelp`, `desc` и автоматического закрытия
  открытой безопасной worktree.
- Полный `lua tests/run.lua` и headless UI regression suite.
